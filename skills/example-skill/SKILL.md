# Example Skill

Это демонстрационный скилл. Он существует, чтобы:

1. Показать корректный формат `SKILL.md` с YAML frontmatter (`name`,
   `description`, необязательное `when_to_use`).
2. Дать индексу `SkillsIndex` валидную папку для сканирования при ручной
   проверке (`skills/example-skill/SKILL.md`).
3. Проиллюстрировать, как `read_skills` возвращает полное содержимое файла
   вместе с относительным путём к папке скилла.

## Как пользоваться

Когда задача соответствует описанию выше, вызови `read_skills` со всеми
подходящими именами одним вызовом, например `read_skills(names=["example-skill"])`.
Затем следуй инструкциям ниже перед тем, как приступать к работе.

## Шаги

1. Прочитай инструкции целиком.
2. Если внутри есть ссылка на дополнительные файлы (например `REFERENCE.md`
   в этой же папке), прочитай их через `read_file`, используя путь к папке,
   который вернул `read_skills`.
3. Выполни задачу в соответствии с инструкциями.

## Ссылки

Дополнительные детали смотри в `REFERENCE.md` (в этой же папке) — он
загружается отдельно через `read_file`, а не через `read_skills`.
