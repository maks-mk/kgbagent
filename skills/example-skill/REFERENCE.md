# Example Skill — Reference

Этот файл демонстрирует вспомогательный документ скилла. Он НЕ индексируется
как отдельный скилл (нет frontmatter и это не `SKILL.md`) и загружается только
по запросу через `read_file`, когда основной `SKILL.md` на него ссылается.

## Зачем нужен отдельный REFERENCE.md

Основной `SKILL.md` держат коротким: только то, что нужно для маршрутизации и
первых шагов. Объёмные справочные материалы (таблицы, спецификации, длинные
примеры) выносят в отдельные файлы, чтобы не раздувать контекст, пока они реально
не понадобятся.

## Пример справочного содержимого

- Поле frontmatter `name` — уникальный идентификатор скилла в индексе.
- Поле `description` — что делает скилл и когда его применять; попадает в
  системный промпт (с мягким лимитом длины).
- Поле `when_to_use` — необязательное уточнение условий применения.
