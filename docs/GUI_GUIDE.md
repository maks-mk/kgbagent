# GUI

## Transcript

Streaming-ответы, tool cards с аргументами и результатами, summary-сообщения, статусные notice. Повторный префейс модели после выполнения инструментов подавляется с учётом нечёткого совпадения (fuzzy matching), чтобы избежать дублирования текста при минимальных расхождениях.

Полная история переписки (`transcript_messages`) сохраняется в checkpoint отдельно от сжатого контекста модели: автосуммаризация удаляет старые сообщения только из контекста LLM, но не из истории чата в UI. Сессии, созданные до внедрения этой схемы, могли потерять старые сообщения при compaction — восстановить их автоматически нельзя.

## Индикатор автосуммаризации

Кольцо рядом с composer показывает заполнение контекста до порога автосуммаризации (`SESSION_SIZE`):

- Tooltip содержит только процент: `20% left until auto-summary.` (сколько осталось до автосуммаризации).
- При достижении порога: `Auto-summary will run on the next step.` — суммаризация выполнится на следующем шаге агента.
- При `SESSION_SIZE=0` индикатор скрыт (автосуммаризация выключена).
- Дуга показывает использованную долю: синяя — обычный режим, янтарная — заполнено 85%+, зелёная — автосуммаризация готова к выполнению. Процент считается от `SESSION_SIZE` (например, `80000`), без учёта внутреннего soft-margin, который лишь защищает от преждевременного сжатия.

## CLI Output Widget

Для `cli_exec` вывод команды (stdout/stderr) отображается в реальном времени прямо в карточке инструмента, по мере поступления чанков. После завершения карточка автоматически сворачивается (с короткой задержкой для успешных команд). Команды с ненулевым exit code, использующие его как часть нормального протокола (`grep`, `rg`, `vulture`, `pytest`, `diff` и др.), не помечаются как ошибка — вывод возвращается с префиксом `Exit Code: N`.

## Composer

- Вставка файлов через `Add files…`, drag-and-drop или clipboard paste
- `@`-mention popup с файлами и директориями текущего workspace (обновляется динамически)
- Нормализация текста перед отправкой: `\r\n` → `\n`, удаление control-символов
- Лимит 10 000 символов на запрос с inline-предупреждением при усечении

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Enter` | Отправить сообщение |
| `Shift+Enter` | Новая строка |
| `Ctrl+N` | Новый чат |
| `Ctrl+B` | Показать / скрыть боковую панель |
| `Ctrl+I` | Показать / скрыть inspector-панель |
| `↑` / `↓` в пустом composer | История отправленных сообщений |
